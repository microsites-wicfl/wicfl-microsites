# Qualified call: the definition

**v1.0 · 10 Sep 2026 · Owner: Victor · Closes backlog item W-100**

Gate B (`GATE_B_MODEL.md`) measures success in qualified calls per site per month. Nobody had
written down what "qualified" means. That is not a detail to settle in March when the report
comes in: the definition decides what the phone system has to record, and the phone system is
wired before Site #1 launches on 9 October.

This document exists so Kevin approves a definition instead of the report inventing one after
the fact. The starting definition below already appears in `GATE_B_MODEL.md` (v1.0, 26 Aug);
this is that same definition, pulled out on its own so it can be approved or edited without
reopening the whole Gate B model.

---

## The starting definition

> A call from a person in the site's service area, about a product the site sells, lasting
> longer than 60 seconds, that was not a wrong number, a solicitation, an existing client
> calling about an existing policy, or a repeat call from someone already counted.

Kevin: accept as written, or edit any part of it. If you change the 60-second threshold or any
of the exclusions, that's fine, just say what changes.

## What has to exist on launch day, once the definition is set

1. **A way to apply it.** GoTo call recording or disposition tagging, so a real person can
   listen to or tag a call against this definition instead of guessing from the call log.
2. **A weekly habit, not a quarterly one.** Someone tags calls as they come in. Nobody can
   classify 120 days of calls from memory the week Gate B lands in March.
3. **A named owner for the tagging.** Not decided yet. Candidates: Pavel (he already owns
   monthly performance reporting), or whoever at Walker currently handles the inbound line.

Items 1 and 3 are new work, not yet scheduled. Item 1 depends on the tracking number existing
in GoTo at all, which is **W-024**, still open. Once W-024 is picked up, wire it so disposition
tagging (or recording) is on from day one rather than retrofitted after the sites are live.

## Why this is set now and not in March

Same reasoning as the Gate B bar itself: a definition written after the data arrives gets
shaped by the data. Whatever the calls looked like will read as the natural definition, and the
gate stops being able to fail. Written down now, before a single call has come in, it can't be
quietly bent to fit whatever happened.
