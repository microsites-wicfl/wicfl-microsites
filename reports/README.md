# Reports

Un reporte por prompt ejecutado. Mismo `NNN` y mismo slug que su prompt en `../prompts/`.

**Todo prompt genera reporte**, aunque la tarea tome 30 segundos.
El formato esperado está en `../prompts/TEMPLATE.md`.

Sin reporte no hay registro de qué se ejecutó, qué decisiones se tomaron ni qué se
descubrió. Si algo sale mal en seis meses, no hay forma de reconstruirlo.
