## Decisiones tomadas

El sitemap usa `getCollection("pages")` y `routeForPageId` para que haya una única fuente de
verdad para las rutas, incluido el prefijo de idiomas. Omite `lastmod`: el repo no tiene una
fecha de modificación fiable por página.

El JSON-LD se serializa en el layout y reemplaza `<` antes de insertarse en el script, para que
los valores de configuración no puedan cerrar la etiqueta. Se usa `is:inline` para que Astro no
procese el bloque JSON-LD como un script de aplicación.
